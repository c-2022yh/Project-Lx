# Pinecone body-lean motion draft v1

Built-in image_gen using the first idle pose cropped from the preceding concept sheet. Four transparent PNG crops are saved under LeanFrames; these are visual drafts and require final pivot/shape continuity review before runtime use. Existing Flower prefab is unchanged.

Order: Idle, Prepare (backward lean), Fire (slight forward lean), Recovery. No scale detachment, no eye color change and no seed baked into body frames. Projectile is a separate future runtime sprite.

## Prompt

Precise sprite animation sheet edit. Use ONLY the provided single pinecone creature as the locked character reference. Make ONE 2x2 four-frame animation pose sheet on true transparent background. All four sprites must be exact copies of this same character design, same scale count, scale shapes, face opening size, TWO cute ROUND CREAM EYES, colors and simple thick dark teal outlines, flat cel shading, continuous flat woody base. Facing RIGHT in all frames. The ONLY animation is a small upper-body lean around the fixed base. NO SCALE OPENS, DETACHES, LIFTS, DISAPPEARS OR CHANGES SHAPE. NO MOUTH/JAW MOVEMENT. NO PROJECTILES, NO SEEDS, NO PARTICLES, NO SPEED LINES anywhere on the sheet. The projectile will be a separate runtime object and must not appear in this character art. No angry eyes or red glow.
Read top-left to top-right to bottom-left to bottom-right: 1 IDLE exactly reference upright stance. 2 WINDUP upper body leans subtly BACK to LEFT about 6 degrees, anchored at bottom center, without changing or lifting the ground-contact base. 3 FIRE upper body leans slightly FORWARD to RIGHT about 4 degrees, still same unchanging cute face and closed overlapping scales, no projectile shown. 4 RECOVER upper body almost upright, about 1 degree back, returning to idle. Make the small lean actually distinguishable but restrained. Each frame same uniform square cell, same character size and identical base bottom-center anchor and ground baseline. Generous margins so no clipping, no overlap, entire creature visible. No feet, legs, roots, arms, new appendages, backgrounds, ground platform, labels or text. This is a motion study of a stationary planted cone rocking backward then nudging forward, not walking, hopping, stretching or spitting. Keep existing reference design unchanged except for gentle upper-body lean.
