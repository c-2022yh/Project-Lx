# 초토화 설정 및 확인

## 연결

`Relic_Berserk → RFX_Berserk → ScorchedEarth.asset` 연결을 유지한다. 폭주 유물 **장착 후**, 각성 상태에서 Q를 다시 누르면 사용한다. 일반 스킬 슬롯은 사용하지 않는다.

## 동작

- 기본값은 일반탄 11발과 마지막 강화탄 1발이다. `Projectile Count`는 강화탄을 포함한 총수다.
- 준비 중 등 뒤 부채꼴 탄환이 플레이어 위치와 바라보는 방향을 따라간다. 양 끝에서 번갈아 발사한다.
- 시전 시작 시 주변의 살아 있고 가리지 않은 적을 거리순으로 찾고, 탄환마다 순환 배정한다. 적이 하나면 모두 집중한다.
- 발사 직후 `Outward Duration` 동안 바깥으로 이동한 후 유도한다. 살아 있고 활성화된 목표는 바꾸지 않는다.
- 목표가 죽거나 비활성화되면 탄환의 현재 위치에서 가장 가까운 유효한 적을 찾는다. 대체 목표가 없으면 직진하다 수명이 끝난다.
- 비행 중 지형은 기본적으로 통과한다. 최초 탐색과 재탐색은 `Sight Obstacle Layer`로 시야를 검사한다. 현재 값은 Ground다.
- 일반탄은 단일 피해이며 넉백을 억제한다. 강화탄은 명중하거나 수명이 끝나면 범위 피해를 한 번 적용한다. 동일 적의 여러 콜라이더는 중복 피해를 받지 않는다.
- 피해는 Q를 누를 때의 각성 공격력으로 확정한다. 기본 합계는 전탄 명중 시 마법 공격력의 `11 × 0.25 + 1.5 = 4.25`배다. 방어·피해 증폭 등은 기존 피해 시스템을 따른다.
- 시전 중 걷기와 방향 전환을 허용하고, 다른 공격·스킬·새 점프 입력은 막는다. 시전 중 기력 감소를 멈추며 강화탄 폭발 시 각성을 종료한다.
- 대시 취소 시 대기 중 탄환을 제거하고 각성을 종료한다. 이미 발사한 탄환은 유지한다. 피격 경직·사망·비활성화·유물 해제·외부 각성 종료도 남은 발사를 정리한다.

## Inspector

`Assets/ScriptableObjects/Skills/ScorchedEarth.asset`의 `Barrage Configuration`에서 개수, 탐색 반경, 준비 시간, 연사 간격, 유도 시작 시간, 속도, 회전 속도, 수명과 각 피해 배율을 조절한다.

`Windup Time`은 준비 연출 앞에 추가되는 지연이며 현재 0이다. 실제 부채꼴 대기는 `Preparation Duration = 0.3`이다. `Finisher Delay = 0.18`은 일반 연사 간격 이후 강화탄에 추가되는 지연이다. 종료 후 `Recovery Time = 0.2` 동안 스킬 상태를 유지한다. 공통 `Active Time`은 이 스킬의 연사·비행 시간을 제어하지 않는다.

제공한 `ScorchedEarthShard`, `ScorchedEarthFinisher`, `ScorchedEarthHit`, `ScorchedEarthExplosion` 프리팹을 이미 연결했다. 탄환은 기존 Flower 씨앗 스프라이트를 붉게 조정한 임시 외형이고, 명중은 기존 HitSpark 애니메이션을 재사용한다. 준비 효과 프리팹은 선택 사항이다. 전용 보주 파편/여우불 아트와 플레이어 전용 모션은 아직 추가하지 않았다.

탄환 외형을 교체할 때는 제공한 탄환 프리팹의 SpriteRenderer 또는 자식 비주얼을 바꾼다. 이동·충돌은 `ScorchedEarthProjectile`이 담당하므로 기존 `ProjectileHitbox`, 자동 소멸 스크립트나 물리 이동 컴포넌트를 함께 붙이지 않는다. 잔상은 발사 시 생성된다.

## 검증과 남은 Play Mode 확인

Unity Roslyn으로 전체 런타임 C# 소스를 컴파일했다. 실제 스킬·투사체·타겟·PlayerSkill·행동 상태 소스와 모의 Unity 생명주기/물리 쿼리를 사용한 34개 검사가 통과했다. Unity 에디터의 실제 물리·입력·렌더링 검증은 수행하지 않았다.

Play Mode에서 다음을 확인한다.

1. 폭주 미장착 시 Q는 각성만 수행하고, 장착 시 각성 중 Q가 초토화를 시작한다.
2. 적 한 마리/여러 마리에서 전탄 집중/분산 배정과 탄환의 벌어졌다 모이는 궤적이 보인다.
3. 목표 사망·비활성화 후 탄환 위치 기준으로 재탐색하고, 적이 전혀 없으면 Q 사용 기회를 유지한다.
4. 준비 중/연사 중/강화탄 비행 중에 대시한다. 남은 발사는 멈추고 발사된 탄환은 유지된다.
5. 강화탄 명중 및 수명 종료 모두 폭발과 각성 종료가 한 번만 일어난다. 여러 콜라이더를 가진 적도 폭발 피해는 한 번이다.
6. 기력이 거의 없는 상태에서도 시전이 마무리되며, 피격·사망·폭주 해제 후 대기 탄환과 스킬 상태가 남지 않는다.
7. 좁은 지형·좌우 방향 전환에서 배치, 잔상, 명중 이펙트 크기와 Sorting Layer를 조정한다.
