# 초토화 설정 및 확인

## 연결과 동작

`Relic_Berserk → RFX_Berserk → ScorchedEarth.asset` 연결을 유지한다. 폭주 유물 장착 후 각성 상태에서 Q를 다시 누르면 사용한다. 일반 스킬 슬롯은 사용하지 않는다.

- 등 뒤 부채꼴로 탄환 12발을 0.15초 동안 모은 뒤 같은 프레임에 전부 발사한다. 준비 중에는 플레이어 위치와 바라보는 방향을 따라간다.
- 탄환은 0.04초 동안 바깥으로 벌어진 뒤 초당 30의 속도, 초당 최대 2160도 회전으로 빠르게 유도한다. 경로 길이 차이로 연속 명중한다. 별도 강화탄과 마지막 범위 폭발은 없다.
- 시전 시작 시 주변의 살아 있고 가리지 않은 적을 거리순으로 찾고 탄환마다 순환 배정한다. 적이 하나면 모두 집중한다. 유효한 적이 전혀 없으면 사용 기회를 소비하지 않는다.
- 살아 있고 활성화된 목표는 유지한다. 목표가 죽거나 비활성화되면 탄환 위치 기준 가장 가까운 유효 적을 찾는다. 대체 목표가 없으면 직진하다 수명 2초가 끝나면 소멸한다.
- 비행 중 지형은 기본적으로 통과한다. 최초 탐색과 재탐색은 `Sight Obstacle Layer`로 시야를 검사하며 현재 값은 Ground다.
- 모든 탄환은 단일 피해를 주고 넉백을 억제한다. 명중 시 해당 탄환은 소멸한다.
- Q를 누르는 시점의 각성 공격력으로 피해를 확정한다. 기본 전탄 명중 합계는 기존과 같은 마법 공격력의 약 4.25배이며, 한 발당 약 0.35416667배다. 방어·피해 증폭 등은 기존 피해 시스템을 따른다. 탄환 수를 조절하면 총 피해량도 달라진다. 범위 폭발의 주변 피해는 제거된다.
- 시전 중 걷기와 방향 전환을 허용하고 다른 공격·스킬·새 점프 입력은 막는다. 시전 중 기력 감소를 멈추며 모든 탄환의 명중·수명 종료·제거가 끝나면 각성을 종료한다. 이후 공통 후딜 0.2초가 적용된다.
- 대시 취소 시 대기 탄환을 제거하고 각성을 종료한다. 이미 발사한 탄환은 유지한다. 피격 경직·사망·비활성화·유물 해제·외부 각성 종료도 대기 탄환과 시전을 정리한다.

## Inspector와 외형

`Assets/ScriptableObjects/Skills/ScorchedEarth.asset`의 `Barrage Configuration`에서 개수, 탐색 반경, 준비 시간, 유도 시작 시간, 속도, 회전 속도, 수명과 발당 피해 배율을 조절한다. 발사 간격과 강화탄 관련 설정은 제거했다. `Windup Time`은 준비 연출 전 추가 지연이며 현재 0이다. 공통 `Active Time`은 탄환 비행 시간을 제어하지 않는다.

일반 탄환과 명중 효과 프리팹 연결을 유지한다. 기존 강화탄·폭발 프리팹은 이 스킬에서 사용하지 않는다. 탄환 외형은 일반 탄환 프리팹의 SpriteRenderer 또는 자식 비주얼에서 수정한다. 이동·충돌은 `ScorchedEarthProjectile`이 담당하므로 기존 `ProjectileHitbox`, 자동 소멸 스크립트나 물리 이동 컴포넌트를 함께 붙이지 않는다. 잔상은 발사 시 생성된다.

## Play Mode 확인

코드 컴파일은 실제 Unity 입력·물리·렌더링 검증을 대신하지 않는다.

1. 폭주 미장착 시 Q는 각성만 수행하고, 장착 시 각성 중 Q가 초토화를 시작한다.
2. 준비 후 12발이 동시에 발사되고 적 한 마리/여러 마리에게 빠르게 집중/분산 명중한다. 마지막 강화탄이나 범위 폭발은 발생하지 않는다.
3. 목표 사망·비활성화 후 재탐색하며, 적이 없을 때 사용 기회를 유지한다.
4. 준비 중 대시하면 대기 탄환이 사라진다. 발사 후 대시하면 비행 중 탄환은 유지되고 각성은 종료된다.
5. 전탄 명중, 일부 수명 종료, 외부 탄환 제거 상황에서도 각성과 행동 상태가 정리된다.
6. 기력이 거의 없는 상태에서도 시전이 마무리되며 피격·사망·폭주 해제 후 대기 탄환이나 행동 제한이 남지 않는다.
7. 좌우 방향 전환과 가까운 적/먼 적에서 유도 궤적·명중 간격·잔상·이펙트 크기를 확인한다.
