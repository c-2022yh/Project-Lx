# UI 효과음 설정

Play Mode를 종료한 뒤 **Project Lx > Audio > Select Audio Catalog**를 엽니다.
Inspector의 **Sounds**에서 아래 Sound 항목의 **Clip**에 음원을 넣습니다.
Clip이 비어 있으면 해당 동작은 무음입니다. Volume과 Minimum Interval도 이곳에서 조절합니다.

| Sound | 재생 시점 |
|---|---|
| UIHover | 일반 UI 컨트롤과 내용이 있는 유물·스킬 슬롯에 마우스가 진입할 때 |
| UIEquip | 스킬 장착, 교체, 스킬 슬롯 이동에 성공했을 때 |
| UIEquipSword | 검 유물 장착·교체 성공 |
| UIEquipOrb | 보주 유물 장착·교체 성공 |
| UIEquipBody | 신체 유물 장착 성공 |
| UIUnequip | 유물·스킬 해제에 성공했을 때 |
| UIReject | 제단 밖에서 변경 시도, 코스트·장착 제한, 잘못된 종류의 칸, 잠긴 스킬칸 등으로 조작이 거절됐을 때 |
| UIAcquire | 획득 알림 팝업의 각 항목이 실제 표시될 때 |
| UITabChange | 유물↔스킬 탭 전환, 유물 필터·정렬 변경 시 |
| UIChestOpen | 상자를 열어 유물 선택 카드가 성공적으로 표시될 때 한 번 |

## 동작 규칙

- 마우스 우클릭·드롭과 키보드 운반은 동일한 장착·해제 처리에서 결과음을 재생합니다.
- 이미 장착된 것을 같은 자리에 놓거나 빈 슬롯을 누르는 동작은 결과음을 재생하지 않습니다.
- 유물 장착음은 종류별 항목에서 지정합니다. 각 Clip이 비어 있으면 해당 종류의 장착은 무음이며, UIEquip으로 자동 대체하지 않습니다. 해제음은 UIUnequip을 공통 사용합니다.
- 창을 열 때 표시되는 제단 안내와 마우스오버 안내에는 거절음이 없습니다.
- 유물↔스킬 탭 이동은 닫기·열기음 대신 UITabChange 한 번을 사용합니다. 창 자체를 열거나 닫을 때는 기존 WindowOpen / WindowClose를 사용합니다.
- 결과음이 발생한 프레임에는 자동 등록된 일반 버튼 클릭음을 생략합니다. 버튼에 명시적으로 설정한 Custom Sound는 유지합니다.
- UIAcquire는 획득 팝업에 연결되어 있습니다. 유물 선택 확정과 팝업 등장 양쪽에서 중복 재생하지 않습니다.
- UIChestOpen은 상자의 유물 선택창 등장음입니다. 카드 마우스오버는 UIHover, 버튼 클릭은 기존 UIClick을 사용합니다. 후보가 없어 창이 열리지 않거나 이미 열린 창에 다시 열기 요청이 들어오면 등장음은 재생하지 않습니다.
- 기존 설정의 UI·Master 음량과 음소거가 적용됩니다. 신규 5개 항목의 음원은 기본적으로 비어 있습니다.

## Play Mode 확인

음원을 지정한 뒤 제단에서 장착·교체·해제, 제단 밖 거절, 코스트 초과,
마우스와 Q/E 탭 전환, 유물 필터, 획득 팝업을 확인합니다.
Unity 참조를 사용한 별도 C# 컴파일은 통과했으며, 실제 입력과 청음 확인은 Play Mode에서 필요합니다.
