# 플레이어 각성 효과음

Play Mode를 종료하고 `Assets/Prefabs/Player/Player.prefab`을 엽니다.
**PlayerAwakening > Awakening Audio**에서 음원을 지정합니다.

| 항목 | 재생 시점 |
|---|---|
| Ready Sound | 각성에 필요한 현재 기력과 최대 기력 조건을 새로 만족할 때 한 번 |
| Start Sound | 각성 입력이 승인되어 도입 애니메이션·연출을 시작할 때 |
| End Sound | 실제 각성 상태가 종료될 때. 살아 있는 상태에서 자연 종료하거나 외부에서 종료한 경우 |

각 항목의 Clip에 하나를 넣거나, Clip을 비우고 Clips에 여러 변주를 넣습니다.
Volume과 Pitch Range도 이곳에서 조절합니다. 기본 Channel은 SFX이며 Clip은 모두 비워두었습니다.
별도 AudioSource는 필요하지 않습니다.

## 재생 규칙

- 시작부터 기력이 충분하거나 컴포넌트를 다시 켠 경우에는 준비 완료음을 내지 않습니다.
- 같은 기력 상태의 반복 이벤트는 준비 완료음을 반복하지 않습니다. 기력을 사용한 뒤 다시 조건을 충족하면 재생할 수 있습니다.
- 각성 중, 각성 도입 중, 각성 차단 상태, 사망 상태에서는 준비 완료음을 내지 않습니다.
- 각성 차단 해제와 도입 취소는 현재 준비 상태를 조용히 다시 기록합니다.
- 실패한 각성 입력에는 Start Sound가 없습니다.
- Start Sound는 도입 시작에 연결되어 있으며 도입이 끝난 뒤 능력치가 적용되는 OnAwakeningStarted 이벤트 시점과 다릅니다.
- 종료 시 아직 남은 발동음은 정리합니다. 도입 중 취소는 발동음을 멈추고 End Sound를 내지 않습니다.
- 사망 시에는 기존 사망음과 겹치지 않도록 End Sound를 내지 않습니다.
- 컴포넌트 비활성화 시 이 컴포넌트가 재생한 각성 소리를 정리하고 기력 이벤트 구독을 해제합니다.

기존 기력 소모량·각성 시간·이동 및 전투 보너스·시각효과는 변경하지 않았습니다.

## 확인

전체 C# 별도 컴파일, 준비 상태 전환 14개 검사와 프리팹 설정 검사를 통과했습니다.
실제 기력 충전 → 각성 도입 → 유지 → 종료, 도입 중 취소/사망, 각성 중 사망,
각성 종료 후 Reflux 기력 회복, 씬 전환과 재활성화는 Play Mode에서 청음·확인이 필요합니다.
