# 늑대 엘리트 설정

## 크기를 변경할 때의 높이 판단

늑대의 탐지, 추적 해제, 공격 선택은 이제 양쪽 **물리 몸통 콜라이더의 바닥 높이**를 비교한다. 같은 바닥에 서 있으면 루트 Transform이나 스프라이트 피벗 높이가 달라도 높이 차이는 거의 0이다. Scale과 Collider Offset/Size 변경은 현재 월드 Bounds에서 자동 반영된다. 접촉 피해용 트리거, 비활성 콜라이더, 별도 Rigidbody에 속한 콜라이더는 제외한다. 몸통 콜라이더가 없는 경우만 해당 캐릭터의 루트 Y를 대신 사용한다.

- `Enemy Wolf AI > Max Attack Height Difference`: 공격 시작 시 허용하는 **발밑 높이 차이**. 현재 0.8을 유지한다. Scale 때문에 3으로 늘릴 필요가 없다.
- `Enemy AI > Detection Range Y / Lose Range Y`: 늑대에서는 각각 발견/추적 해제에 사용하는 발밑 높이 차이다. 다른 종류의 적은 기존 루트 기준을 유지한다.
- 물기/돌진 선택 거리와 탐지 가로 거리는 월드 단위이며 Scale에 따라 자동으로 늘어나지 않는다. 공격 선택 범위와 실제 피해 판정 박스는 별도이다.
- 먼저 같은 평지에서 발견과 공격을 확인하고, 이후 높은 발판과 점프 상황을 확인한다. 공격 준비가 시작된 뒤에는 플레이어를 다시 추적하지 않는다.

아래에 적힌 크기와 거리 수치는 최초 제작 시 기본값이다. 작업 중 조정한 실제 프리팹/씬 Inspector 값이 우선이며, 이번 높이 수정에서는 그 값을 바꾸지 않았다.

`Assets/Prefabs/Enemies/Enemy_Wolf.prefab`을 테스트 씬의 평평한 Ground 위에 배치한다. 스프라이트와 체력바 참조는 연결되어 있다. 루트가 발 위치가 아니라 이미지 캔버스 중앙이므로, CapsuleCollider2D의 바닥을 지면에 맞춘다. 초기 Scale은 `(0.75, 0.75, 1)`이다.

## 동작

- 대기/순찰 → 플레이어 탐지 → 추적.
- 가로 거리 1.8 이내, 높이 차이 0.8 이내면 물기. 쿨타임에는 대기한다.
- 가로 거리 3~6, 높이 차이 0.8 이내면 돌진. 돌진 쿨타임에는 접근한다.
- 공격은 지면에 서 있을 때 시작한다. 시작 후 플레이어가 점프해도 방향을 바꾸거나 추적하지 않는다.
- 물기: 예고 0.4초 → 0.16초 동안 0.35만큼 전진하며 입 앞 판정 → 후딜 0.55초. 종료 후 쿨타임 1.2초.
- 돌진: 웅크리기 0.6초 → 0.4초 동안 4만큼 지상 이동 → 후딜 0.8초. 종료 후 쿨타임 2.5초.
- 공격당 같은 플레이어에게 한 번만 피해를 준다. 공격 중에도 체력은 감소하지만 준비/실행/후딜 동안 넉백과 피격 경직은 적용하지 않는다.
- 벽/절벽을 감지하면 전진을 중단하고 후딜로 넘어간다. 플레이어와 닿아도 돌진은 계속된다.
- 평상시/예고/후딜에는 공격 판정이 없다. 몸통은 Player와 물리 충돌하지 않는다. 사망하면 공격을 중단하고 기존 사망/보상 처리를 사용한다.
- 비활성화/재활성화 시 공격 상태, 타격 기록, 쿨타임을 초기화한다.

## Inspector

- `Enemy Wolf AI`: 물기/돌진 선택 거리, 공격 시작 시 허용 높이 차이. 거리는 월드 단위이다.
- `Enemy Wolf Attack > Bite / Ground Charge`: 각 공격의 예고/판정/후딜/쿨타임, 전진 거리, 피해 계수, 단계별 스프라이트.
- `Hitbox Offset / Size`: 프리팹 로컬 단위. 방향에 따라 X 오프셋이 반전되고 루트 Scale이 반영된다. 선택 시 Scene Gizmos에서 물기는 노랑, 돌진은 빨강으로 보인다.
- `EnemyContactHitbox` ??? BoxCollider2D: ?? ?? ??. ?? Offset `(0, -1)`, Size `(2.7, 1.3)`, Is Trigger ??, EnemyContact ???.
- `Target Layers`: Player. `Ground Layers`: Ground. 지형에 다른 물리 레이어를 쓰면 공격 컴포넌트와 공통 Enemy AI/Knockback의 Ground Layer도 함께 맞춘다.
- `Enemy Animation`: Idle 3장, Run 4장, Hit 1장, Death 3장. `Sprite Faces Right`와 `Idle When Stationary`가 켜져 있다. 별도의 Animator Controller는 사용하지 않는다.
- `Enemy Health`: 초기 HP 30, 기력 보상 20. `Enemy Stats`의 물리 공격력 1과 각 패턴 피해 계수 2는 임시 밸런스값이다.

자동 스폰에 사용하려면 해당 씬의 `EnemyPooler > Enemy Prefabs` 목록에 이 프리팹을 추가한다. 이번 변경에서는 씬과 풀 목록을 수정하지 않았다.

## Play Mode 확인

1. 지면 위에 배치하고 Idle/Run, 좌우 반전, 물기 입 위치를 확인한다.
2. 물기 예고 중 뒤로 빠지거나 뒤로 넘어가면 공격이 빗나가고, 후딜에 접근해 반격할 수 있는지 확인한다.
3. 돌진 예고를 보고 기본 점프로 넘을 수 있는지 확인한다. 실패하면 먼저 빨간 판정 높이/위치와 예고 시간을 조절한다.
4. 공격 중 타격 시 HP는 줄고 늑대는 밀리지 않는지, 후딜 종료 후에는 일반 넉백이 돌아오는지 확인한다.
5. 벽/절벽 양쪽 방향에서 돌진 종료를 확인한다. 경사/일방통행 발판은 실제 사용하는 지형에서도 확인한다.
6. 공격 중 처치 시 사망 모션만 재생되고, 다시 활성화한 개체가 정상적으로 행동하는지 확인한다.

C# 컴파일과 직렬화 참조 검사는 전투 감각이나 점프 회피 성공을 증명하지 않는다. 위 항목은 Unity Play Mode 확인이 필요하다.
